# TKIT Al-Ishlah

A minimalist concept of a kindergarten website. Albeit minimalist, this project envisions how a school website should look like: to showcase the fun, colorful world of children education, not a boring blocks of grown-ups styled layout came from generic, out-of-can blog template.

## Built With:

- **Astro** - Static site generator
- **Alpine.js** - Lightweight reactivity
- **HTMX** - Dynamic HTML interactions
- **Tailwind CSS** - Utility-first styling
